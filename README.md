# LZT.Market Parser

Парсер объявлений с LZT.Market с минималистичным черно-белым дизайном.

## Особенности

- Парсинг объявлений с LZT.market
- Черно-белый минималистичный дизайн
- Фильтрация по категориям и цене
- Ссылка на покупку через Telegram
- Адаптивный дизайн
